Wewe test Parent

A browser stand-in for a phone running the Parent screen — speaks the same relay wire protocol (see signal-server/src/server.ts) and uses the browser's own WebRTC stack, so it can join a real room, get accepted/rejected by a real Monitor, and actually play the audio it receives. Useful when you don't have enough physical phones to exercise the multi-listener/invite-mode paths — open this file in a few separate browser tabs (each tab gets its own deviceId, persisted in sessionStorage so it survives a reload but not a closed tab) to stand in for extra phones.
